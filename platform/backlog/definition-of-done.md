# Definition of Done — готовність до запуску v1 (CLT-01)

> **Єдиний гейт запуску.** Кожен пункт чеклиста запуску з `docs/roadmap.md` (розділ «Чеклист запуску v1») зв'язаний із задачею, що його закриває. **Запуск = усі пункти цього документа закриті**: задача пункта має статус `done` в Індексі задач (`README.md`) **і** чекбокс у roadmap поставлений. Пункт без задачі або задача без пункту — помилка синхронізації, виправляється одразу.
>
> Правила:
> 1. Зміна чеклиста в roadmap → правка тут в одному коміті (обидва файли завжди узгоджені).
> 2. Задача закриває пункт, лише якщо її Done-критерії прийняті; сам статус — джерело правди в індексі, тут не дублюється.
> 3. Пункти «не код» (дані, ПРРО, GBP) не мають задач — приймаються за фактом чеклиста; власник — засновник/опс.
> 4. Ревізія: при кожній зміні фаз roadmap або при старті M3 (перед гейтом запуску).
