# T-4457 · Сторінка «Мій код» реферальної програми

- **Stage**: M4 (phase 8) · **Tags**: backend, frontend, client-app · **Complexity**: junior · **Depends on**: T-220, T-142
- **StoryPoints**: 3
- **Status**: review

## What

Розділ у клієнтських поверхнях: мій рефер-код, посилання/QR шерінгу, статус запрошених (прийшов/не прийшов), бали за запрошення (T-142), ліміти програми (скільки за місяць). Копіювання посилання і share sheet.

## Why

Реферальний механізм (T-220) сповільнюється, якщо клієнт не знає, як поділитись; видимий код і статус — найкращий нагадувач вступити в програму.

## Sources

- referrals.md; T-220 (механіка), T-142 (бали); client-screens.md

## Done

- [x] Код + посилання + QR у кабінеті/додатку; share працює: `GET /referrals/:clientId/code-page` повертає `code`, `shareUrl`, `qrPayload` (той самий URL для QR-генератора) і готовий `shareText`; код створюється при першому відкритті й повторно не змінюється
- [x] Статуси запрошених (без особистих даних про них): `invited` (запрошено, ще не прийшов), `arrived` (візит підтверджено, бонус у очікуванні), `rewarded` (бонус нараховано), `revoked`; у видачі лише `Запрошений #N`, час запрошення/візиту/нарахування, без імен та id
- [x] Індикатор «залишилось N місць» за лімітом: `monthly {limit, used, remaining, limitReached, month}` у таймзоні програми (Europe/Kyiv), скасовані запрошення не займають місце
- [x] Анти-фрод: `pointsEarned` рахується лише за `rewarded`, `pointsPending` — за `qualified`; клік по лендінгу балів не дає
- [x] 13 нових тестів (20 у модулі): посилання/QR/share-текст, нормалізація коду, статуси й відсутність персональних даних, бали, місячний ліміт і його межа/перехід місяця, валідація конфігурації, автогенерація коду, чужий реферер, HTTP-мапінг 400

## Risks

- [x] **Фрод**: показ бонусу лише за «реально прийшов» (REWARDED), не за «прийшов на лендінг» (PENDING балів не дає; T-220)
- [x] Порядок у видачі стабільний (найновіші перші), підписи не розкривають, хто саме запрошений

- Автентифікація клієнта: `clientId` у шляху, `ClientSessionGuard` — окрема картка.
