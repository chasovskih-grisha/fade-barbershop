# T-1300 · Мобільний додаток барбера (20/20)

- **Етап**: M2 (фаза 25) · **Теги**: frontend, mobile, high-risk · **Складність**: senior · **Залежності**: T-082, T-083, T-084
- **StoryPoints**: 20

## Що
Реалізувати нативний мобільний додаток для барбера (iOS/Android): календар, прийом дзвінків, клієнтські картки, графік, push-сповіщення. Використовувати React Native + Expo.

## Навіщо
Ключовий інструмент для барбера. Збільшує ефективність роботи, зручність управління записами.
