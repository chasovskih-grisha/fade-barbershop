# T-500 · Платіжна інтеграція (25/25)

- **Етап**: M5 (фаза 30) · **Теги**: backend, high-risk, finance · **Складність**: senior · **Залежності**: T-093, T-094
- **StoryPoints**: 25

## Що
Інтегрувати платіжну систему: Stripe/PayPal для онлайн оплати, депозити, повернення. Реалізувати веб-хуки, валідатори, транзакційний лог. Підтримка карток, Apple/Google Pay.

## Навіщо
Критично для доходів. Без оплати немає бізнесу. Депозити зменшують no-show. Повернення — обов'язково для довіри.

## Джерела вимог
- ADR 0024 (платежі)
- `docs/payments.md`

## Залежності
- T-500a (тестування платежів)
- T-500b (UI оплати)
