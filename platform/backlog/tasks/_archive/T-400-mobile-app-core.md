# T-400 · Мобільний додаток клієнта (20/20)

- **Етап**: M5 (фаза 25) · **Теги**: frontend, mobile, high-risk · **Складність**: senior · **Залежності**: T-071, T-072

## Що
Реалізувати нативний мобільний додаток (iOS/Android) з основними функціями: пошук барберів, запис на послуги, історія візитів, лояльність, push-сповіщення. Використовувати React Native + Expo для швидкого старту.

## Навіщо
Ключовий канал для залучення клієнтів, особливо молодої аудиторії. Підвищує лояльність і зручність користування.
