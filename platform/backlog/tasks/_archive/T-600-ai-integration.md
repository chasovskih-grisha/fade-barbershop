# T-600 · AI-інтеграція (30/30)

- **Етап**: M6 (фаза 35) · **Теги**: ai, backend, high-risk · **Складність**: senior · **Залежності**: T-050, T-051
- **StoryPoints**: 30

## Що
Інтегрувати AI-моделі: рекомендації послуг на основі історії, автоматичні описи, AI-чат для клієнтів, персоналізовані знижки. Використовувати OpenAI API, Redis для кешування, Outbox для асинхронних відповідей.

## Навіщо
Диференціатор від конкурентів. Підвищує upsell і клієнтську задоволеність. AI-опису зменшують навантаження на барберів.
