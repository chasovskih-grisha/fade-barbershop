# T-1400 · API-шлюз

- **Етап**: M5 (фаза 30) · **Теги**: backend, integration, high-risk · **Складність**: senior · **Залежності**: T-001, T-002
- **StoryPoints**: 15

## Що
Створити шлюз: маршрутизація, автентифікація (JWT), rate limiting, caching, моніторинг. Використовувати Kong/Nginx. Забезпечити єдину точку входу для всіх сервісів.

## Навіщо
Безпека, навантаження, централізований контроль. Підтримка мікросервісної архітектури.
