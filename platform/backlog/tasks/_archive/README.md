# Архів задач

Задачі, вилучені з активного індексу `backlog/index/`, коли їхній статус `done`
і жодна відкрита задача більше на них не посилається в `Depends on:`. Файли зберігаються
з історією (`git mv`), вміст не редагується. Тека `_archive` ігнорується `docs:validate`,
тож архівні файли не потребують рядка в індексі.
