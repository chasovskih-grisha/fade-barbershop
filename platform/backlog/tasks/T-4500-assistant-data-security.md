# T-4500 · Асистент: безпека даних діалогу

- **Stage**: M7 (phase 28) · **Tags**: backend, security, experimental · **Complexity**: middle · **Depends on**: T-280
- **StoryPoints**: 5

## What

CW надався токенів у діалогах асистента (T-280): жодні персональні дані (телефон, адреси, платіжі) не передаються в LLM без мінімізації (маска) і згоди; журнал діалогів зберігається з політикою TTL (T-4490), відкликання (Delete діалог) працює, інструменти виконують тільки дозволені доменні use cases через ACL (ADR 0020).

## Why

Асистент без security-шару = дамба для персональних даних у промпт; це експериментальна поверхня, ризик критичний.
