# T-2300g · Мова статті

- **Stage**: M5 (phase 30) · **Tags**: frontend, content, i18n · **Complexity**: middle · **Depends on**: T-2300a, T-4613a
- **StoryPoints**: 5

## What

Підключити статтю до вже вирішеної моделі перекладу. Другої таблиці перекладів і другого редактора не заводити.

ADR 0053: українська без префікса, англійська з `/en/`, усі переклади в одній `Translation`, none значення — показ українського, slug лишається латиницею. T-4613a будує таблицю, T-4613b — редактор за `entityType`, T-4613c — маршрути і `hreflang`.

Цей Slice:

- Реєструє для `entityType: article` поля `title`, `excerpt`, `body`, `seoTitle`, `seoDescription`, `coverAlt` і підписи тегів. Slug, дати, обкладинка-URL і прапорець обраної не перекладаються.
- Публічна сторінка `/en/blog/{slug}` і англійська стрічка беруть ці значення. none перекладу — на екрані український текст, сторінка не 404.
- Тег в URL той самий (`/blog/tag/{tag}` і `/en/blog/tag/{tag}`). Міняється підпис, не адреса.
- Якщо редактор T-4613b уже вміє довге текстове поле за схемою — окремий екран перекладу статті не робити. Якщо не вміє тіло — Add поле тіла в той редактор, не новий розділ адмінки.
- `blocks` для англійської сторінки парсяться з перекладеного `body` тим самим парсером. Сирий HTML в перекладі відхиляється так само, як в оригіналі.

## Why

Стаття українською на `/en/blog/…` — це не друга мова, а та сама сторінка з іншим префіксом. Пошук отримає дубль. Поля треба назвати зараз, разом із моделлю a, інакше T-4613b збере переклад послуги і не знатиме, що робити з тілом статті.

## Done

- [ ] Схема статті в `Translation` покриває перелічені поля і відхиляє невідомі ключі
- [ ] `/en/blog/{slug}` показує перекладені заголовок, тіло і alt, коли вони є
- [ ] Без перекладу сторінка показує український оригінал і не відповідає 404
- [ ] Slug в обох мовах один
- [ ] Перекладене тіло з HTML не публікується
- [ ] Окремого розділу «переклади блогу» в адмінці none

## Risks

- [ ] **Дубль в індексі.** Сторінка з чистим українським фолбеком не повинна прикидатися унікальним англійським текстом: прапорець «переклад неповний» віддається в T-4613c для `hreflang`/canonical. Цей Slice прапорець обчислює (усі поля порожні → фолбек), розмітку мови не вигадує
- [ ] **tags двома мовами в одному масиві статті.** Підпис тегу живе в `Translation`, не другою копією масиву на `Article`
- [ ] **Роз'їзд парсерів.** Англійське тіло йде в парсер a. Власного «англійського markdown» none

## Розмежування

- Маршрути `app/[locale]`, перемикач, `hreflang` — **T-4613c/d**
- Словники інтерфейсу («Усі статті», «Записатися») — **T-4612**, не поля статті
- Пошук англійською по українському тілу — поза слайсом: `q` шукає мовою запису, який віддав API для цієї локалі
