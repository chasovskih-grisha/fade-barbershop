# T-2400 · Ролі і права доступу в адмінці (15/15)

- **Stage**: M5 (phase 30) · **Tags**: backend, security, high-risk · **Complexity**: senior · **Depends on**: T-020, T-012
- **StoryPoints**: 15

## What
Implement рольову модель в адмінці: супер-адмін, менеджер, барбер. Різні права доступу до секцій/дій. Захист API ендпоінтів. UI фільтрація по ролі. Тестування всіх ролей.

## Why
Безпека і контроль доступу. Менеджери не бачать конфіденційні дані. Барбери бачать лише свій розклад і клієнтів. Супер-адмін — повний доступ.
