# T-2400b · Фільтрація UI по ролі (5/15)

- **Stage**: M5 (phase 30) · **Tags**: frontend, ux · **Complexity**: middle · **Depends on**: T-020
- **StoryPoints**: 5

## What
Add фільтрацію екранів адмінки по ролі: менеджер бачить локації, клієнтів, статистику; барбер бачить лише свій розклад і клієнтів; супер-адмін бачить все.

## Why
Користувацький інтерфейс без зайвих елементів. Безпека — конфіденційні дані не відображаються.
