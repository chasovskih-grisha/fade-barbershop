# T-4426 · Біометричний вхід (mobile)

- **Stage**: M2 (phase 5) · **Tags**: mobile, security · **Complexity**: middle · **Depends on**: T-014, T-070
- **StoryPoints**: 5

## What

Face ID / Touch ID / біометрія пристрою замість повторного OTP: ключ у Keychain/Keystore, локальна аутентифікація до доступу, інвалідація при виході (T-4422) і при зміні пароля/скиданні.

## Why

Клієнт відкриває додаток щодня; входи по дзвінку-коду дратують — біометрія знімає терття (мотивація CLT-01: передбачити баркан-флоу).

## Sources

- client-screens.md §0 (вхід); ADR 0017 (сесії); products.md §3 (мобільний)

## Done

- [ ] Біометричний вхід працює після первинного OTP; повторний запит при невдачі
- [ ] Вихід/скидання інвалідизує біометричний ключ
- [ ] Хардвер-граничні випадки (без біометрії, у приватності) в тестах

## Risks

- [ ] **Підміна акаунта**: біометричний ключ прив'язується до пари (user, refresh-seed) — після безпечного входу
