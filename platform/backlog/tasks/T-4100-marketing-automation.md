# T-4100 · Маркетингова автоматизація

- **Stage**: M6 (phase 40) · **Tags**: backend, marketing, integration · **Complexity**: senior · **Depends on**: T-3101, T-3201
- **StoryPoints**: 25

## What
Marketing automation платформа: сегмент-будівельник (RFM, LTV, behavior, custom), кампанії (email/SMS/push/in-app), дріп-послідовності (trigger → wait → action → condition → action), A/B Tests (subject, content, timing, channel), персоналізація (merge tags, dynamic content, product recommendations), автоматизація життєвого циклу (onboarding → activation → retention → win-back), ROI трекінг (open/click/conversion/revenue), GDPR compliance (unsubscribe, preference center).

## Why
Масштабування маркетингу. Персоналізація = конверсія. Життєвий цикл клієнта автоматизовано. Дані для оптимізації.
