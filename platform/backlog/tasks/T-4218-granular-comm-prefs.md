# T-4218 · Гранулярні налаштування комунікацій

- **Stage**: M6 (phase 40) · **Tags**: backend, ux · **Complexity**: middle · **Depends on**: T-3100, T-3902
- **StoryPoints**: 12

## What
Preference center: **Канали** — email / SMS / push / in-app / WhatsApp / Viber (незалежні налаштування); **Категорії** — транзакційні (підтвердження запису, нагадування, платежі, OTP) / маркетингові (промо, newsletter, win-back) / безпека (логін, зміна пароля, 2FA) / операційні (техроботи, оновлення політик); **Керування** — enable/disable по канал×категорія, ліміти частоти (max 1 маркетингове/тиждень), тихі години (per часовий пояс користувача, дефолт 22:00–08:00), мовні налаштування, digest-режим (щоденне/щотижневе зведення); **Адміністрування** — UI для користувача (кабінет/мобільний), admin override (лише транзакційні), export/import, лог згод (GDPR Art. 7).

## Why
Користувач контролює свій inbox. Ліміти частоти = менше відписок. Compliance = законна вимога.
