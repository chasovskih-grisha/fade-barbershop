# T-4599 · Зв'язка Google Search Console ↔ GA4 (M5)

- **Stage**: M5 (перед запуском v1) · **Tags**: seo, analytics, marketing · **Complexity**: junior · **Depends on**: T-250, T-303, T-2600a, T-4593
- **StoryPoints**: 3

## What

Підтвердження домену в Search Console і зв'язування з GA4, щоб органічний трафік і органічні конверсії були одним звітом, а не двома незв'язаними.

### Кроки
1. **Властивість домену** (не URL-prefix): Search Console → Add property → Domain → `fade.com.ua`. Підтвердження — DNS TXT (CNAME/TXT) через провайдера DNS з T-303; альтернатива (meta-тег) гірша — ламається при редиректі. Окремої властивості для booking none: запис — шлях `/booking` і він `noindex`.
2. **Зв'язок з GA4**: у GSC → Settings → Associations → Google Analytics → вибрати властивість `Fade Web` (з T-4593). Зв'язок односторонній: GSC → GA4.
3. **Карта сайту**: `https://fade.com.ua/sitemap.xml`. `/booking` у карту не входить (`noindex`). Якщо генератор не існує — Create `apps/web/src/app/sitemap.ts` (Next metadata route) у межах цієї задачі; якщо генератор уже існує (Verify в `apps/web/src/app/sitemap.ts` і в index-файлах SEO-задач) — підключити його, не створювати другий.
4. **Перевірка індексації** через 1–3 дні: чи бачить GSC фактичний контент, чи є критичні помилки обходу.
5. **Звіт**: у GSC → Performance → Conversions з'являються GA4-конверсії (`booking_confirmed`, `payment_captured`); окремий розріз «organic → booking_confirmed» в GA4 (source/medium = `google / organic`).

### Межі (свідомо не робимо)
- Не робимо аудит технічного SEO, Core Web Vitals-дашборд, аналіз беклінків, роботу з контентом/ключовими словами — це T-2600a і T-250.
- Не робимо SEO для `admin.fade.com.ua` (закритий від індексації, у GA4 і GSC не входить).

## Why

Органіка — часто найдешевший канал для локального бізнесу, але без зв'язки з GA4 вона виглядає як «візити без записів» і не впливає на пріоритети. Зв'язавши властивості, ми бачимо не «organic = 900 показів», а «organic = 900 показів → 12 записів».

## Done

- [ ] Властивість домену `fade.com.ua` підтверджена через DNS TXT; підтвердження в GSC зелене
- [ ] Властивість GA4 `Fade Web` зв'язана з GSC; статус зв'язку Active
- [ ] Sitemap відповідає 200, валідний, містить `fade.com.ua`; `/booking` у карті none
- [ ] Через 3 дні: GSC бачить індексацію реальних сторінок, помилок критичних none
- [ ] У GSC Performance з'являються GA4-конверсії
- [ ] У GA4 зріз `google/organic` → `booking_confirmed` дає ненульове значення
- [ ] `robots.txt` не блокує публічні сторінки вітрини випадково; `/booking` лишається `noindex` (перевірка)
- [ ] Скриншоти збережено в задачі; факт підтвердження та дату зафіксовано

## Risks

- [ ] **DNS-провайдер**: T-303 не вирішений — підтвердження домену блокується на ньому; Prepare інструкцію, виконати одразу після рішення
- [ ] **Затримка 1–3 дні**: GSC не покаже конверсії миттєво — не перевіряти «за хвилину»
- [ ] **Один хост**: запис живе на `fade.com.ua/booking`, не на окремому домені (ADR 0017, 2026-10-01). Другий хост із тим самим контентом розмиє звіт Search Console
- [ ] **`robots.txt` на стейджі**: стейдж не індексується (T-4590), але не заблоковується, щоб не зливати валідацію — Verify robots окремо
