# T-3203 · Конструктор звітів

- **Stage**: M6 (phase 40) · **Tags**: backend, frontend, analytics · **Complexity**: middle · **Depends on**: T-3200
- **StoryPoints**: 12

## What
Конструктор звітів: drag-drop полів (dimensions/measures), фільтри, групи, сортування, візуалізація (таблиця/графік/півпільник), збереження шаблонів, доступ по ролях (T-2400), API для embedded.

## Why
Гнучкість без коду. Адміністратори створюють власні звіти. Embedded для клієнтів (B2B).
