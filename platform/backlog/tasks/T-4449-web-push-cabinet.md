# T-4449 · Web Push для кабінету

- **Stage**: M3 (phase 7) · **Tags**: backend, notifications · **Complexity**: junior · **Depends on**: T-032, T-4410
- **StoryPoints**: 3

## What

Push Notification у браузері для web-кабінету (VAPID): підписки на коло «кабінет відкритий у фоновому», доставка нагадувань/статусів поверх пулу мобільних (T-080) з дедуплікацією між поверхнями; екран згоди (тимчасовий запит), повага до тихих годин.

## Why

Клієнт web без додатка — основний CLT-01 не мобільний у 50% випадків; без web push він пропускає нагадування, якщо додаток не встановлений.
