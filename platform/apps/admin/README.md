# @fade/admin — адмінка засновника

Next.js-додаток для ролі `admin`. Окремий домен і сесія від публічного сайту. Каркас зібрано (T-001) — бізнес-код додається за фазами.

## Призначення

Локації, персонал, календар мережі, клієнти, послуги, CMS блогу (публікації одразу на сайт і в додаток), статуси оплат.

Не для барберів (їм mobile) і не для гостей. Приймальні критерії: `docs/acceptance-criteria/` (ADM-сценарії: оплати, AI-моніторинг, референси у календарі, управління мережею — локації, барбери, послуги, ціни, години роботи; бонус «кожен 7-й візит», модерація відгуків). Специфікація екранів: `docs/admin-screens.md`.

## Запуск

З кореня платформи:

```bash
pnpm --filter @fade/admin dev    # next dev, порт 13002
```

Усі мутації — через API, не через Prisma з цього пакета.

## Доступ

Лише `Role = admin`. Немає публічних сторінок.
