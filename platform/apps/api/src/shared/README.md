# Shared kernel (всередині API)

Лише те, без чого контексти не можуть розмовляти між собою: базові типи подій, `LocationCode`, `Money` (UAH), помилки.

Не складати сюди бізнес-правила запису, чату чи блогу. Якщо правило живе в одному контексті — лишайте його там.

Дублікат пакету `packages/domain-shared` з’явиться лише якщо ті самі типи знадобляться web/admin/mobile. До того — тримати типи в API.
