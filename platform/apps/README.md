# Apps

Клієнти платформи. Каркаси зібрано (T-001) — це робочі заготовки з health-скриптами, тестами й Docker-образами; бізнес-код додається за фазами.

| Пакет | Продукт |
|-------|---------|
| `web` | Публічний сайт, блог, кабінет клієнта (телефон + OTP) |
| `admin` | Адмінка засновника |
| `mobile` | iOS + Android: клієнт, барбер, блог |
| `api` | Модульний моноліт |

Розвиток — за фазами в `docs/roadmap.md`, не всі чотири одразу.
