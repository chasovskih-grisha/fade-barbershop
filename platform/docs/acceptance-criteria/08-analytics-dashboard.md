# 08. Дашборд KPI засновника (`analytics`)

> Фіча: KPI-дашборд для засновника — виручка, завантаженість крісел, середній чек, no-show, скасування, конверсія запису, повторний запис, виручка на годину крісла, злив через знижки. **Жорстка вимога v1**: без дашборду запуск не вважається повним — весь проект існує для калібрування unit-economics, а рішення по цінах/лояльності/знижках без даних — це вгадування.
>
> Контекст: **`analytics`** (новий, Supporting) — **read-model проєкції** на подіях `scheduling`, `billing`, `loyalty`, `discounts`. Не джерело правди; лише роль `admin`. Проєкції будуються ідемпотентно за подіями (той самий патерн, що ADR 0009).

## Метрики (правило)

- [ ] **ANL-001. Виручка за день** (`RevenuePerDay`) = Σ `PaymentCaptured` (депозити + решта, у т.ч. на місці) за день; розбивка по локаціях (фаза 9+) і барберах.
- [ ] **ANL-002. Завантаженість крісла** (`ChairOccupancy`) = завершені хвилини / доступні хвилини крісла (день/тиждень); по кріслах — видно, чи 2 крісла заповнені.
- [ ] **ANL-003. Середній чек** (`AvgTicket`) = виручка / завершені візити за період; по барберах і послугах.
- [ ] **ANL-004. No-show rate** = no-show візити / усі заброньовані за період; по барберах. Потребує події `AppointmentNoShowed` у `scheduling` (статус no-show вже існує в продуктах — подія додається).
- [ ] **ANL-005. Конверсія запис → завершений** (`ConversionRate`) = завершені / підтверджені записи за період — скільки записів реально дійшли до крісла.
- [ ] **ANL-006. Злив через знижки** (`DiscountLeakage`) = Σ `AppliedDiscounts` + вартість безкоштовних візитів (`AgreedPrice`) за період; у грн і % від Σ `AgreedPrice`; **по типах** (VIP / промокод / правило / лояльність) — видно, чи кампанії окупаються.
- [ ] **ANL-007.** Джерело — події через outbox; проєкції ідемпотентні (повторна доставка не змінює результат). Зміна цін/знижок після запису не змінює історію (снепшоти `AgreedPrice`/`AppliedDiscounts`, ADR 0006/0007).
- [ ] **ANL-008. Скасування** (`CancellationRate`) = скасовані / усі заброньовані за період; по барберах. Подія `AppointmentCancelled`. Перенесення (`Reschedule`) у чисельник не входить.
- [ ] **ANL-009. Повторний запис** (`RepeatBookingRate`) = завершені візити, на момент `AppointmentCompleted` у того самого клієнта є інший запис зі стартом пізніше за кінець цього / завершені візити; по барберах. Уже існуючий майбутній запис рахується: гість вийшов із наступним візитом. Правило в залі — `business/operations/sop/booking.md`.
- [ ] **ANL-010. Виручка на доступну годину крісла** (`ChairHourRevenue`) = виручка періоду (той самий Σ `PaymentCaptured`, що ANL-001) / доступні години крісла (знаменник ANL-002 у годинах); грн/год; по кріслах і барберах. Зайнятий час і гроші за цей час — різні числа.

## Admin (дашборд)

- [ ] **ANL-ADM-01.** Розділ «Аналітика»: фільтр-бар (період: день/тиждень/місяць/кастом; локація; барбер) → картки KPI → графіки (виручка по днях, no-show по барберах, злив по типах знижок).
- [ ] **ANL-ADM-02.** Кожен KPI — з tooltip-формулою і порівнянням до попереднього періоду (▲/▼).
- [ ] **ANL-ADM-03.** No-show, скасування, конверсія і повторний запис — розбивка по барберах (для операційних розмов, без фінансів барбера).
- [ ] **ANL-ADM-04.** Злив через знижки — по типах і по промокодах (які коди реально працюють).
- [ ] **ANL-ADM-05.** Оновлення без ручних дій: звіт за вчорашній день повний; «сьогодні» — поточний стан (не остаточний до кінця дня).
- [ ] **ANL-ADM-06.** (Опційно) Експорт у CSV/Excel за період.

## Відкриті питання

1. **Частота оновлення проєкцій**: нічний перерахунок vs near-real-time — технічне рішення при імплементації (вартість проєкцій мала).
2. **Експорт** (ANL-ADM-06): у v1 чи пізніше.
3. **Операційні метрики барбера** (власна завантаженість/no-show без фінансів) — окремо від FDB-BAR-02; за рішенням, не блокує дашборд.
