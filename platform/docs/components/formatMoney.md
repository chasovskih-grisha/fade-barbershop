# formatMoney

Єдиний формат ціни в гривнях (uk-UA, `Intl.NumberFormat('uk-UA', { style: 'currency', currency: 'UAH' })`, 0 копійок).

## API

```ts
function formatMoney(amount: number): string   // 700 → "700 ₴"; 10000 → "10 000 ₴"
```

Тисячі розділяються нерозривним пробілом (UX-політика дизайн-системи).

## Do / Don't

- ✓ у компонентах грошей (`PriceBreakdown`) і всіх цінах на екранах.
- ✓ для негативних значень знижки — брати `Math.abs` на боці відображення.
- ✗ не форматити ₴ конкатенацією `amount + ' ₴'`.
- ✗ не використовувати `toFixed`-±копійкові варіанти — тільки цілі гривні.
