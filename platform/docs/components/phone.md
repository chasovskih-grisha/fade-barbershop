# Phone-хелпери

Нормалізація українських телефонів: введення → E.164 (зберігання/API), зворотне форматування для відображення.

```ts
phoneDigits(value: string): string        // "+38 (067) 123-45-67" → "380671234567"
nationalDigits(value: string): string     // → "0671234567" (10 цифр, з провідним 0)
toE164(value: string): string             // 10 цифр → "+380671234567"; незаповнений — ""
formatPhoneInput(value: string): string   // → "+38 (067) 123-45-67" покроково
```

## Приклад

```ts
const e164 = toE164('067 123 45 67');          // "+380671234567"
const shown = formatPhoneInput(e164);          // "+38 (067) 123-45-67"
```

## Do / Don't

- ✓ зберігати/відправляти тільки `toE164` (формат усього домену — E.164).
- ✓ використовувати в `PhoneInput`; інші поля телефону не використовувати.
- ✗ не зберігати «красиві» рядки з маскою в БД/API.
- ✗ не писати власну маску в екрані/компоненті.
