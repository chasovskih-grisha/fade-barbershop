# Як додати календар FADE до Google Calendar / Apple Calendar

1. Увійдіть у кабінет барбера та відкрийте налаштування профілю / розкладу.
2. Скопіюйте персональне посилання експорту календаря у форматі ICS (`GET /calendar/export.ics?barberId=...&token=...`).
3. У Google Calendar натисніть «Інші календарі» → «Додати за URL» (From URL) і вставте посилання.
4. Календар оновлюється автоматично (кеш 5 хвилин) у режимі «лише для читання».
