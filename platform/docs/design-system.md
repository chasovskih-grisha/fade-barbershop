# Дизайн-система платформи

> Єдина візуальна мова і бібліотека компонентів для трьох поверхонь: сайт (`apps/web`), адмінка (`apps/admin`), mobile (`apps/mobile`). Імплементація — задача **T-004** (M0). Стиль успадковує `references/design-direction.md` (мінімалізм + брутальний + футуристичні акценти); бренд зафіксований — **FADE** (`brand/FADE_FINAL_STATUS.md`), палітра — **monochrome-first** (рішення 2026-09-18, `brand/color-type.md`). Цей документ — **єдине джерело правди** значень для UI. Правило: екран без токенів системи не проходить рев'ю так само, як код без тестів.

## Чому окремий документ

Три поверхні × 27 фаз: без системи кожна фаза винаходить кнопки, кольори і сітки заново — бренд-стиль (темний преміум) розмивається за кілька місяців, а кожен новий екран стає повільнішим. Компоненти тут **виведені з реальних екранів** (`docs/*-screens.md`, `booking-flow.md`), а не «бібліотека заради бібліотеки» (KISS/YAGNI — `engineering-principles.md`).

## Архітектура реалізації

- **`packages/design-tokens`** — єдине джерело токенів: JSON → CSS-змінні для web/admin, тема NativeWind для mobile. Один елемент правди для кольору/типографіки/проміжків на всіх поверхнях.
- **`packages/ui`** — React-компоненти web/admin. Mobile-компоненти — `apps/mobile/ui` на NativeWind з тих самих токенів (нативна поведінка — жестами/навігацією Expo).
- Стек стилів: Tailwind (web/admin) + NativeWind (mobile) — одна утилітна філософія, токени як theme. Деталі бандлінгу — в T-004.
- **Заборона**: hex/px-значення в коді екранів — тільки токени. Гейт у CI (stylelint/ESLint), як LOC-ліміт ADR 0019.

## Токени

### Кольори — темна тема базова

Бренд темний; палітра **monochrome-first** (рішення 2026-09-18): сіра шкала — фірмовий вираз «less, but better», синій — світло у фото/інтер'єрі, колір у UI — лише семантика. Значення зафіксовані з production kit `brand/fade_01_kit` (Night/Bone/Ink/Paper) + сіра шкала; реалізація в токенах — T-004 як є, без перегину:

| Токен | Значення | Правило |
|-------|----------|---------|
| `surface.base` | `#0E0E10` (Night) | База всіх поверхонь |
| `surface.raised` | `#151619` | Картки, шіти, дропдауни |
| `surface.sunken` | `#0A0A0C` | Вкладені зони, поля вводу |
| `border.default` / `border.strong` | `#26282C` / `#3A3D42` | Глибина через рівні поверхонь і 1px-межі, не через тіні (брутальний стиль) |
| `text.primary` | `#F4F4F6` (Bone) | Контраст на base 17.6:1 (AAA) |
| `text.secondary` | `#9CA0A8` | Контраст 7.35:1 (AA) |
| `text.muted` | `#898D94` | Контраст 5.7:1 (AA) — підписи, placeholders, muted-стани |
| `accent` | інверсія: заливка `#F4F4F6`, вміст `#0E0E10` | Дії (primary CTA) і виділення; ніколи — фонові заливки великих площ |
| `accent.blue` | `#5C7CFA` (steel blue, 5.6:1 на base; фінальний тон — контраст-тест T-004) | Лише: AI-флоу (прогрес генерації, AI-бейдж) і `focus-visible`; малими площами |
| Семантика | `success` / `warning` / `danger` / `info` | Стани візитів, оплат, валідації — однакові на всіх поверхнях; дозуються до бейджів/пілів |
| Інтеракція | `interactive` / `interactive.hover` / `interactive.active` | CTA і лінки; hover/active — сходинками сірої шкали, не кольором |

- **Світла тема**: `Paper #F4F1EA` + `Ink #111111` (з kit) — для роздруківок, email, документів; не для основних поверхонь.
- **Металевий (срібний) градієнт монограми** — маркетинг-обробка: ковери, банери, соцмережі (`brand/fade_01_kit`). В UI — плаский Bone; градієнти в інтерфейсі заборонені.
- **Синій = світло, не фарба**: rim-light у фото/відео, LED у вітрині, підсвітка інтер'єру — фотомова бренду (`references/design-direction.md`); у UI синій живе тільки в `accent.blue`.

**Статуси візиту — семантична мапа, не декоративні кольори**: `booked` (нейтральна) · `confirmed` (info) · `in_progress` (accent) · `completed` (success) · `cancelled` (muted) · `no_show` (danger) · waitlist-hold (warning). Мапа фіксується один раз (компонент `StatusPill`) — календар адмінки, картка барбера і список клієнта показують статус однаково.

### Типографіка

- Два сімейства — **дефолт зафіксований (2026-09-19, очікує підтвердження засновника після тест-драйву)**: **Fixel Display** (заголовки, ціни, hero) + **Fixel Text** (UI, форми). Повна українська кирилиця, 9 ваг × 2 ширини, безкоштовно для комерції; файли вже в kit — `brand/fade_01_kit/fonts/` (woff2 web + ttf Expo), план підключення — там само. Шорт-лист і альтернатив — `brand/typography-shortlist.md`; тест-драйв — `brand/fade_01_kit/docs/font-shootout.html`. Після підтвердження — зняти статус і оновити `brand/color-type.md`.
- Правило пари: wordmark/lockup — тільки кастомний (`brand/logo/system/lockup.svg`), шрифт ніколи не замінює лого (див. `brand/fade_01_kit/docs/wordmark-research.html`).
- Шкала: `caption 12 · body 14 (admin) / 16 (клієнтські поверхні) · 18 · 20 · 24 · 32 · 40`. Лінійна висота 1.4–1.6; display — tracking щільніший.
- **Клас = ключ токена.** Tailwind бере ключ пресета дослівно, тож `fontSize.bodyLg` — це `text-bodyLg`; кебаб-варіант `text-body-lg` не існує, CSS для нього не генерується і текст мовчки успадковує розмір. Гейт `no-phantom-classes` (T-004) ловить саме такі мертві класи: `text-body-lg` (ключ — `bodyLg`), `text-h7`, `text-fg-primary` (токен — `fg`), `max-w-9xl`, `rounded-xxl`, сирий `bg-red-500`. Токена він вимагає лише там, де словник токенів є (кольори, шкала типографіки, radius, max-width, line-height, font-family) — у решті випадків клас проходить як ядрова утиліта Tailwind: вирівнювання й перенос тексту, сторони/стилі/товщина меж і `border-spacing-*`, `divide-*` (включно з `divide-x-reverse`), ширина та зміщення `ring`/`outline`, насиченість і дефолтні родини шрифтів, шари й градієнти фону (`bg-cover`, `bg-clip-text`, `bg-gradient-to-b`), `line-clamp-*`, ключові ширини (`max-w-full|fit|prose|screen-*`), глобальні CSS-ключові слова й ключові кольори (`none`, `auto`, `inherit`, `unset`, `revert-layer`, `transparent`, `current`, `black`, `white`), числа (`border-2`, `w-1/2`, `max-w-0`) і довільні значення в дужках (`text-[11px]`, `max-w-[13rem]`). Варіанти знімаються узагальнено — `aria-[sort=ascending]:`, `supports-[display:grid]:` і `[&>*]:` теж розпізнаються.
- **Спадкові класи — окремий список, не мовчазний виняток.** Класи, яких у `tokens.json` ще немає, але які використовують екрани (`text-sm`, `text-xs`, `text-body-s`, `text-2xl`, `text-h5`, `text-h6`, `text-primary`, `text-danger`, `text-red-600`), перелічені в `LEGACY_CLASSES` самого правила. Список — борг токенів, а не дозвіл: клас, який з'явиться в `tokens.json`, зі списку випадає, і гейт одразу його ловить.
- Контейнер контенту — `max-w-container` (з `tokens.grid.web.container`); решта `max-w-sm…max-w-7xl` — compat-токени з `tokens.grid.web.max*`, вони проходять гейт, але нові екрани беруть канонічний клас.
- Числа: табличні цифри (tabular-nums) у таблицях, цінах, календарі.
- **Email — системний стек, не Fixel (T-4611a).** У листах `Fixel Display`/`Fixel Text` не використовуються: Gmail вирізає webfont і зовнішні `<style>`, Outlook не підтримує `@font-face` — вигляд «як на сайті» в листі неможливий. Листи беруть системний стек із токена `email.fontStack` (`-apple-system, Segoe UI, Roboto, Helvetica, Arial, sans-serif`), а не рядок у кожному шаблоні. Правило перевіряє CI-гейт `pnpm email:check`. Мінімуми розміру: текст ≥ `email.fontSizeBody` (14), підписи ≥ `email.fontSizeCaption` (12).

### Сітка і проміжки

- Spacing: база 4px — `4/8/12/16/24/32/48/64`.
- Web: 12-колонна сітка; контейнер контенту ~1200px; мобільна ширина — одна колонка.
- Mobile: база 4pt; поля екрана 16; зони великого пальця — низ екрана.

### Радіуси, межі, тіні, іконки, рух

- Радіуси: `sm/md/lg` + `pill` (бейджі, статуси); **конкретика (ревізія 2026-09-21, з прототипу T-053)**: `radius-input = 8` (поля, тайли часу, чипи) · `radius-card = 12` (картки вибору, шіти, модальні) · `pill = 999` (бейджі, статуси). У CSS-змінних kit: `--radius-md = 8` (input-роль), `--radius-lg = 12` (card-роль), `--radius-sm = 4` — лише мікроелементи всередині карток. Дрібніші елементи (тайли слотів, чипи днів) — `radius-input`, не своя величина: менше значень — чистіша система. Тіні мінімальні — elevation через поверхні/контраст. **Маркетинг-ассети на тій самій шкалі (2026-09-21)**: og/insta композити T-053 (OG 1200×630, пост 1080×1080, Stories 1080×1920) і QR-таблички 500×700 перевірені і виправлені — прогрес-сегменти капсульні (`pill`), OTP-комірки та ціновий бейдж — `radius-input`, слот QR-таблички — `radius-card`; позасистемних радіусів (6/1.5) не лишилось.
- Іконки: один набір, stroke 1.5–2, сітка 24px. Змішувати набори заборонено.
- Рух: стримано — 150–250 мс, стандартний easing; жодних анімацій на критичному шляху запису; `prefers-reduced-motion` поважається.
- Зображення: темна контрастна обробка фото; before/after — фіксована пара 2×1; AI-зображення завжди з бейджем (AC 15).

## Компоненти

### Рівні

1. **Primitives** — Button, Input, Select, Checkbox, Badge, Card, Modal/Sheet, Toast, Tabs, Table, Skeleton…
2. **Patterns** — складені з примітивів під домен: `SlotPicker`, `PriceBreakdown`, `StatusPill`, `PhotoUpload`, `GalleryTile`, `ProgressBar`, `RatingStars`, `ChatBubble`, `CalendarDay/Week`.
3. **Shells** — каркас поверхні: web (шапка/футер), admin (сайдбар + таблиці), mobile (таб-навігатор).

### Стани — обов'язкові для кожного інтерактивного компонента

`default · hover · focus-visible · active · disabled · loading · skeleton`; поля додають `error` (текст під полем, не тільки колір). Компонент без описаних станів не приймається. Стан `focus-visible` — скрізь (клавіатура на web/admin).

## Правила UX (політики)

- **Ціна**: показується тільки через `PriceBreakdown`; валюта ₴, тисячі — нерозривний пробіл; «стара ціна + знижка» окремими розрізненими написами заборонена.
- **Дати/час**: uk-UA, 24-годинний формат; «сьогодні/завтра» замість дат, де доречно; час завжди локальний локації.
- **Телефон**: введення з маскою `+38`, відображення `+38 (0XX) XXX-XX-XX`; зберігання — E.164.
- **Доступність**: WCAG 2.1 AA — контраст ≥ 4.5:1 (гейт T-004 = `packages/design-tokens/contrast.mjs` у `pnpm verify`: замірено text.primary 17.56:1, text.secondary 7.35:1, text.muted 5.79:1, `accent.blue` 5.25:1, CTA-інверсія 17.56:1), touch-цілі ≥ 44×44, текст масштабується (без фіксованих висот рядків), alt/ARIA на фото галереї.
- **Форми**: валідація on blur/submit; помилка конкретна («Введіть 6 цифр з SMS»); введення не блокується на кожному натисканні.
- **Деструктивні дії**: клієнт — підтвердження з наслідком («Депозит не повернеться — вікно 4 год»); адмін для незворотних — type-to-confirm.
- **Завантаження**: < 300 мс — нічого; довше — skeleton локальної зони, не спінер на всю сторінку.
- **Consent-патерн** (AI, відгуки, галерея): явний opt-in окремим чекбоксом простою мовою, посилання на деталі; попередньо відмічені чекбокси заборонені.
- **Голос**: короткі твердження, без «!!!», звернення на «ви» (клієнтські поверхні); адмінка — нейтрально-ділова.
- **Щільність**: admin — data-dense (базовий 14, компактні таблиці); клієнтські поверхні — повітря мінімалізму (базовий 16).

## Управління (governance)

- Нова UI-потреба → спершу `packages/ui`; немає — розширити систему, а не клепати локальний компонент у екрані (DRY).
- Кожен компонент: сторінка-документ (usage, do/don't, усі стани) + приклад у пісочниці; інструмент — doc-сторінки на Markdown (`docs/components/*.md`, рішення T-004, 2026-09-21), без Storybook.
- Гейти CI: «тільки токени» (stylelint/ESLint), LOC < 100 (ADR 0019), рев'ю проти цього документа.
- Контраст-токенів: `pnpm --filter @fade/design-tokens verify` включає WCAG-чекер `contrast.mjs` (гейт T-004, 2026-09-21) — див. заміри в §Правила UX.
- Зміни токенів — як ADR: що ламається, хто сповіщений; історія ревізій у кінці файла.
