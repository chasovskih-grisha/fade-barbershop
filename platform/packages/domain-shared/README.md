# @fade/domain-shared

Мінімальний shared kernel для клієнтів API (web / admin / mobile), коли типи знадобляться поза сервером.

Поки код не пишемо. Кандидати:

- `LocationCode` (`CLT-01`)
- `Money` (копійки + `UAH`)
- ідентифікатори як branded string types

Не класти сюди Appointment, Conversation, Article.
