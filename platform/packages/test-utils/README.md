# @fade/test-utils

Спільні e2e-фікстури платформи — єдине джерело правди для тестових даних
(ADR 0019: валідні телефони, FK-впорядкований cleanup, транзитний retry).

## Що всередині

- **testPhone** — валідний +380-номер (12 цифр), унікальний між воркерами й
  усередині сюїти (час + лічильник + uuid-цифра).
- **seedTestLocation** — локація агрегатом (крісла + години) одним nested-create.
- **cleanupTestLocation** — FK-впорядкований cleanup повного піддерева локації
  (outbox лише за booking-ID цієї локації — глобальний deleteMany за
  aggregateType під паралельним бігом видаляв чужі події).
- **seedBarberUser** — User(role: barber) з валідним тестовим телефоном.
- **assignBarber** — прив'язка до локації: staffAssignment + опційне
  availabilityWindow (чужолокаційному барберу віконце не потрібне).
- **seedServiceWithPrices** — послуга з цінами по локаціях одним викликом.
- **seedRawBooking / walkInWindow** — сирий Booking-рядок (перешкода в розкладі,
  без агрегату Appointment) і walk-in на весь день.
- **postWithRetry / patchWithRetry** — повтор транзитних 409 (P2034 Serializable)
  і 500 (насичення пулу) за контрактом клієнта.

## Правила споживання

- Тільки тестовий код (e2e-сюїти, фікстури). У прод-код `apps/*` не імпортувати.
- Нові e2e-сюїти **зобов'язані** використовувати ці хелпери замість сирих
  `prisma.*.create` фіктур і власних retry-циклів.
